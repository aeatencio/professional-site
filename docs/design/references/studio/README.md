# SITE-V1 studio visual references

These five images are design-process checkpoints from the SITE-V1 graphic
direction work. They are kept here to document that process and as visual
inspiration.

They do not describe the current or final implementation. They have no
normative authority. Current product, design and content decisions live in
the repository's present instructions, accepted ADRs, contracts, code and
tests.

These files are not published assets. Do not serve them from the site, place
them under `public/`, or consume them from production code.

Together they formed one visual family and were used as checkpoints for a
later longitudinal page experience. They are historical references, not a
specification.
